## الجزء الأول: المؤشرات (Pointers)

### السؤال 1
ما ناتج تنفيذ الكود التالي؟

```cpp
int x = 10;
int *y = &x;
(*y)++;
cout << x;
```

- **أ)** 10
- **ب)** 11
- **ج)** عنوان x في الذاكرة
- **د)** خطأ في الترجمة

### السؤال 2
ما الناتج المتوقع من الكود التالي؟

```cpp
int x = 10;
int *y = &x;
y++;
cout << *y;
```

- **أ)** 10
- **ب)** 11
- **ج)** قيمة عشوائية من الذاكرة
- **د)** خطأ في التنفيذ (Runtime Error)

### السؤال 3
ما ناتج تنفيذ الكود التالي؟

```cpp
int a = 7;
int *aPtr = &a;
cout << *&aPtr;
```

- **أ)** 7
- **ب)** عنوان a
- **ج)** عنوان aPtr
- **د)** خطأ في الترجمة

### السؤال 4
في نظام 64-bit، ما حجم المؤشر `int *p;` عادةً؟

- **أ)** 4 bytes
- **ب)** 8 bytes
- **ج)** 2 bytes
- **د)** يعتمد على نوع البيانات المشير إليها

### السؤال 5
أي الدوال التالية تغير قيمة المتغير الأصلي المُمرَّر إليها؟

```cpp
void f1(int n) { n = n*n*n; }
void f2(int &n) { n = n*n*n; }
void f3(int *n) { *n = (*n)*(*n)*(*n); }
```

- **أ)** f1 فقط
- **ب)** f2 و f3 فقط
- **ج)** f1 و f2 و f3
- **د)** لا شيء منها

### السؤال 6
أي العبارات التالية صحيحة بالنسبة للكود التالي؟

```cpp
int x = 10;
int *y1 = &x;
int *y2 = new int;
*y2 = 10;
```

- **أ)** y1 و y2 يشيران إلى نفس العنوان
- **ب)** y1 في الـ Heap و y2 في الـ Stack
- **ج)** قيمة *y1 تساوي قيمة *y2 لكن العنوانين مختلفان
- **د)** y2 يشير إلى x

### السؤال 7
ما ناتج تنفيذ الكود التالي؟

```cpp
int a[5] = {1,2,3,4,5};
int *b = a;
cout << b[2];
```

- **أ)** 1
- **ب)** 2
- **ج)** 3
- **د)** عنوان a[2]

### السؤال 8
ما العلاقة بين `*(a + 2)` و `a[2]` عندما يكون a مصفوفة؟

```cpp
int a[5] = {1,2,3,4,5};
cout << *(a + 2);
```

- **أ)** *(a + 2) > a[2]
- **ب)** *(a + 2) < a[2]
- **ج)** *(a + 2) == a[2]
- **د)** لا يمكن المقارنة

### السؤال 9
ما العلاقة بين المخرجات الثلاثة في الكود التالي؟

```cpp
int a[5] = {1,2,3,4,5};
int *aPtr = a;
cout << a << endl;
cout << *aPtr << endl;
cout << &a[0] << endl;
```

- **أ)** المخرج الأول والثاني متساويان
- **ب)** المخرج الأول والثالث متساويان
- **ج)** المخرج الثاني والثالث متساويان
- **د)** كلها متساوية

### السؤال 10
في بيئة G++، ما القيمة المرجح طباعتها من الكود التالي؟

```cpp
int x = 10;
int z = 50;

y++;
cout << *y;
```

- **أ)** 10
- **ب)** 50
- **ج)** قيمة عشوائية
- **د)** خطأ في الترجمة

## الجزء الثاني: المؤشرات والمصفوفات

### السؤال 11
ما الخطأ في الكود التالي؟

```cpp
int a[50] = {1,2,3,4,5};
int *b = a;
for(int i = 0; i < 5; i++)
    cout << b[i];
```

- **أ)** لا يوجد خطأ
- **ب)** تجاوز حدود المصفوفة
- **ج)** المؤشر b لا يمكنه فهرسة المصفوفة
- **د)** يجب استخدام *(b+i) بدلاً من b[i]

### السؤال 12
ما المشكلة في الكود التالي؟

```cpp
int n;
cin >> n;
int a[n] = {0};
```

- **أ)** لا يوجد مشكلة
- **ب)** لا يمكن تعيين حجم المصفوفة ديناميكياً بهذه الطريقة في C++
- **ج)** يجب استخدام new
- **د)** ب و ج كلاهما صحيح

### السؤال 13
ما الميزة الرئيسية لهذا الأسلوب مقارنة بالمصفوفات الثابتة؟

```cpp
int n;
cin >> n;
int *a = new int[n];
```

- **أ)** سرعة أكبر في الوصول
- **ب)** حجم المصفوفة يُحدد أثناء التشغيل
- **ج)** لا تحتاج إلى delete[]
- **د)** تُخزن في الـ Stack

## الجزء الثالث: إدارة الذاكرة الديناميكية

### السؤال 14
ما السلوك المتوقع من الكود التالي؟

```cpp
int *p = new int;
delete p;
cout << *p;
```

- **أ)** 0
- **ب)** قيمة عشوائية (Garbage Value)
- **ج)** خطأ في الترجمة
- **د)** خطأ في التنفيذ مباشرة

### السؤال 15
ما المشكلة في الكود التالي؟

```cpp
int *p = new int[10];
delete p;
```

- **أ)** لا يوجد مشكلة
- **ب)** Memory Leak
- **ج)** يجب استخدام `delete[] p;`
- **د)** خطأ في الترجمة

### السؤال 16
ما اسم المشكلة التالية؟

```cpp
int *p1 = new int;
// ... code ...
// forgot delete p1;
```

- **أ)** Dangling Pointer
- **ب)** Memory Leak
- **ج)** Segmentation Fault
- **د)** Buffer Overflow

### السؤال 17
ما نوع الخطأ المحتمل هنا؟

```cpp
int *a = new int[5];
for(int i = 0; i < 100; i++)
    a[i] = i;
```

- **أ)** Memory Leak
- **ب)** Buffer Overflow
- **ج)** Dangling Pointer
- **د)** لا يوجد خطأ

### السؤال 18
في Java/Python، الذاكرة الديناميكية تُدار تلقائياً بواسطة:

- **أ)** المبرمج
- **ب)** Garbage Collector
- **ج)** المترجم فقط
- **د)** نظام التشغيل

### السؤال 19
لماذا لا يوجد Garbage Collector في C++؟

- **أ)** لأن C++ لغة قديمة
- **ب)** لأن GC يُبطئ التنفيذ ويحتاج موارد إضافية
- **ج)** لأن C++ لا تدعم الذاكرة الديناميكية
- **د)** لأن المؤشرات محظورة في C++

```cpp

- **ب)** unique_ptr يسمح بنسخ واحد فقط

```

- **أ)** 0
- **ب)** 1
- **ج)** 2
- **د)** 5

- **أ)** أسرع في الأداء
- **ب)** تخصيص ذاكرة واحد (Single Allocation) للمؤشر وكتلة التحكم

- **د)** ب و ج كلاهما صحيح
