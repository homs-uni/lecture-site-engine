## الجزء الأول: const مع المؤشرات (6 أسئلة)

### السؤال 1
ما ناتج محاولة ترجمة الكود التالي؟

```cpp
const int x = 10;
int *xPtr = &x;
```

- **أ)** يترجم بنجاح ويعمل بدون أخطاء
- **ب)** خطأ في الترجمة: invalid conversion من const int* إلى int*
- **ج)** يترجم لكن يعطي تحذير (Warning) فقط
- **د)** خطأ في التنفيذ (Runtime Error)

### السؤال 2
ما معنى الإعلان التالي؟

```cpp
const int *xPtr = &x;
```

- **أ)** مؤشر ثابت لا يمكن تغيير العنوان المخزن فيه
- **ب)** مؤشر يمكن تغيير العنوان الذي يشير إليه، لكن لا يمكن تعديل القيمة عبر المؤشر
- **ج)** مؤشر ثابت إلى int ثابت
- **د)** لا يمكن تغيير العنوان ولا القيمة

### السؤال 3
ما معنى الإعلان التالي؟

```cpp
int *const xPtr = &x;
```

- **أ)** مؤشر يمكن إعادة توجيهه إلى عنوان آخر
- **ب)** مؤشر ثابت: لا يمكن تغيير العنوان الذي يشير إليه، لكن يمكن تعديل القيمة
- **ج)** مؤشر إلى int ثابت
- **د)** لا يمكن تغيير العنوان ولا القيمة

### السؤال 4
أي الإعلانات التالية يُنشئ "مؤشراً ثابتاً إلى int ثابت" (لا يمكن تغيير العنوان ولا القيمة)؟

- **أ)** `const int *p;`
- **ب)** `int *const p;`
- **ج)** `const int *const p;`
- **د)** `int const *p;`

### السؤال 5
ما ناتج الكود التالي؟

```cpp
int x = 10;
int *const xPtr = &x;
(*xPtr)++;
cout << x;
```

- **أ)** 10
- **ب)** 11
- **ج)** خطأ في الترجمة
- **د)** سلوك غير محدد

### السؤال 6
ما الخطأ في الكود التالي؟

```cpp
int x = 10;
int *const xPtr = &x;
xPtr++;
```

- **أ)** لا يوجد خطأ
- **ب)** xPtr مؤشر ثابت لا يمكن تغيير العنوان المخزن فيه
- **ج)** يجب تهيئة xPtr عند الإعلان
- **د)** لا يمكن استخدام ++ مع المؤشرات

## الجزء الثاني: مؤشرات الدوال (Pointers to Functions) (5 أسئلة)

### السؤال 7
ما الإعلان الصحيح لمؤشر دالة تأخذ int وترجع void؟

- **أ)** `void *f(int);`
- **ب)** `void (*f)(int);`
- **ج)** `(void *f)(int);`
- **د)** `void *f(int*);`

### السؤال 8
في الكود التالي، ما دور المعامل compare؟

```cpp
void bubbleSort(int *data, int len,
                bool (*compare)(int, int)) {
    for(int i=0; i<len-1; i++)
        for(int j=0; j<len-i-1; j++)
            if(compare(data[j], data[j+1]))
                swap(&data[j], &data[j+1]);
}
```

- **أ)** يحدد عدد عناصر المصفوفة
- **ب)** دالة callback تحدد شروط المقارنة للترتيب
- **ج)** يقوم بعملية المبادلة swap
- **د)** يطبع المصفوفة بعد الترتيب

### السؤال 9
كيف يتم استدعاء دالة عبر مؤشرها؟

```cpp
int add(int a, int b) { return a+b; }
int (*p)(int, int) = add;
```

- **أ)** `p.add(3,4);`
- **ب)** `(*p)(3,4);` أو `p(3,4);`
- **ج)** `add.p(3,4);`
- **د)** `*p(3,4);`

### السؤال 25
ما الخطأ في الكود التالي؟

```cpp
int *allocate(int n) {
    return new int[n];
}
void init(int *p, int n, int val) {
    for(int i=0; i<n; i++) p[i] = val;
}
void print(const int *p, int n) {
    for(int i=0; i<n; i++) cout << p[i] << " ";
}
int main() {
    int *data = allocate(3);
    init(data, 3, 7);
    print(data, 3);
    return 0;
}
```

- **أ)** لا يوجد خطأ، لكن Memory Leak لعدم استخدام delete[]
- **ب)** init يجب أن تستخدم const int*
- **ج)** print لا يمكنها قراءة المصفوفة
- **د)** allocate يجب أن تُمرر معامل const
